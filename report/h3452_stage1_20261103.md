# Order 3452: a verified Z43 compression and compatible border, no full core

Date: 2026-11-03. Work by OpenAI Codex, directed by the repository owner.
Starting commit: `6a3873c228b5642d73834605249b35b2bc544f0f`.
This continues the v=863 suggestion in `report/b3_push_answer.md` section 8.5.
It implements a direct compressed search and a bounded lift baseline, not yet the
proposed Gauss-period S/D solver. Construction and border machinery are the existing
Kumar/EKLO-based `bt_engine.py` and `bt_border.py`; their credits remain applicable.

## Result and scope

- An exact solution of the Z43-compressed equations was found for the S7 host
  `2e93be9718324148`, G = Z2 x Z2 x Z5 x Z43. It passes an independent all-lag
  integer check. Certificate: `data/h3452_stage1.json`.
- A compatible border of width 12 was rebuilt, with every border identity checked
  exactly. Certificate: `logs/h3452/border.json` (existing frame 75).
- No full core, and no H(3452), was found. The first bounded lift search performed
  977,877 opposite-sign swap proposals, over 20 restarts of 100,000 loop iterations.
  Its best candidate still has 794 nonzero residual lags, maximum absolute residual
  56. These are residuals from the required bordered-core target, not raw PAFs.
- The reduced CP-SAT model reports INFEASIBLE for one fixed S14 compression fibre
  even with its full domain. A separately implemented all-lag model returned UNKNOWN
  at 180 seconds. Thus the negative result has **not** been independently confirmed
  and has no exported proof certificate. It does not exclude the S7 host or H(3452).

## The bordered construction

Set K = Z5 x Z43, Q = G/K = Z2^2, and t = 3. Four sign sequences on G (length 860)
must have summed periodic autocorrelation F equal to 3440 at zero, -12 on K minus
zero, and +4 outside K. Their GS array has size 3440; a 12-row/column border gives
3452. The ordinary unbordered Hadamard autocorrelation target would be wrong here.

The multiplier acts trivially on Z2^2 x Z5 and as x -> 4x on Z43. It has order 7.
There are 140 orbits per block: in each of 20 cells, a singleton at zero and six
size-seven cyclotomic classes. This is the report's S7, r140, e71 host.

Compress along N = Z43. Write y_i(q,u) for the resulting four sequences on
Z2^2 x Z5. Each coordinate belongs to

    { -43, -41, -29, -27, -15, -13, -1, 1, 13, 15, 27, 29, 41, 43 }.

This follows exactly from y = epsilon + 7 sum(j=1..6) epsilon_j.
The summed compressed PAF must be 2936 at zero, -516 at (0,u) with u nonzero,
and 172 when q is nonzero. These values come from summing F over N.

The found solution uses only values of absolute value at most 15. Its further
compression along Z5 is:

| block | q=0 | q=1 | q=2 | q=3 | row sum |
|---|---:|---:|---:|---:|---:|
| A | 1 | 1 | 1 | 1 | 4 |
| B | 1 | 1 | 1 | 3 | 6 |
| C | 1 | 1 | 1 | 3 | 6 |
| D | 13 | 15 | 15 | 15 | 58 |

The row sums obey 4^2 + 6^2 + 6^2 + 58^2 = 3452. This alone is not sufficient;
`h3452_validate.py` checks every compressed lag independently.

## Search and verification

`h3452_compress.py` uses exact finite domains, shared quadratic products, and
optional fixed Q-compressions. Unlike the earlier refinement-list method, it does
not materialize all possible full compressed blocks. A known order-2148 compressed
control was recovered in 0.22 seconds, independently checked, and its deliberately
corrupted version rejected (`logs/h3452/control2148.json`).

`h3452_stage1_anneal.py` uses small pools per Q-cell, preserving Q-compressions.
The S7 swap run reached a candidate with two independent lag residuals +4 and -4.
An exact local repair, holding blocks A and C fixed and solving B and D, found the
certificate in 3.52 seconds (`logs/h3452/repair_02.json`). All 20 lag equations were
then verified by `bt_cpsat_level.level_system`, whose group arithmetic does not use
`bt_engine`. Timings are observations from this environment, not performance bounds.

For the S14 host `fbf4f510b2566552`, the additional action is
(q1,q2,u) -> (q2,q1,-u). Two tested fixed z fibres were reported infeasible with
|y| <= 15. The fibre with rows (4,6,6,58) was also reported infeasible without that
restriction, in 91.23 seconds. See the independent-check limitation above. No
conclusion about untested z fibres follows.

## Border and lift

The saved border has X of size 12 x 12, Rh of size 12 x 16, and Ch of size 16 x 12.
All entries are signs. The exact checks are

    X X^T = 12 I,       Rh Rh^T = 16 I,
    Ch Ch^T = I4 tensor Gamma_Q,
    X Ch^T + Rh Mc^T = 0.

Rh and Ch are extended constantly on K-cosets when assembling the full matrix.
The border works for any full core with the recorded Q-compressions; it does not
make the current compressed solution into a full core.

`h3452_lift.py` initializes sign assignments inside this exact compression fibre
and swaps opposite cyclotomic signs within one cell. Every move preserves y.
Its integer quadratic PAF update was compared with direct group autocorrelations
on 100 random two-sign flips. The final saved candidate was rechecked on all 860
lags, and its compression was verified unchanged.

This single fibre contains about 2^339.114 sign quadruples, before the remaining
equations. The initial annealing failure is not evidence of nonexistence. The next
substantive step is a structured lift solver, for example pairing the six Z43
classes under negation and solving the resulting sum/difference equations in
stages. The three negative pairs are the classes represented by (1,2), (3,6),
and (7,9). Cost and feasibility of that solver remain unestablished.

## Reproduce

Dependencies and versions: `logs/h3452/environment.json`.
Run from the repository root; do not use Python's `-O`, which disables assertions.

```sh
python theory/h3452_validate.py
python theory/h3452_stage1_anneal.py --kind s7 --z-index 1 --seed 3 --proposal swap --restarts 200 --steps 100000 --out /tmp/h3452_near.json
python theory/h3452_compress.py --kind s7 --z-index 1 --max-abs 15 --hint logs/h3452/anneal_s7_z1_swap.json --fixed-blocks 0,2 --secs 8 --workers 1 --out /tmp/h3452_repair.json
python theory/h3452_lift.py data/h3452_stage1.json --restarts 20 --steps 100000 --out /tmp/h3452_lift.json
python theory/h3452_crosscheck.py logs/h3452/s14_z1_full120.json /tmp/h3452_crosscheck.json --secs 180
```

Saved heuristic runs record seeds, proposal types, pool sizes, and residuals.
Solver time limits can lead to different search outcomes on other machines.
UNKNOWN and NO_SOLUTION_FOUND are inconclusive; OPTIMAL for a satisfaction model
means the compressed equations were satisfied, not that H(3452) was constructed.
